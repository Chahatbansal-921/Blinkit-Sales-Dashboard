# Blinkit Sales Dashboard
An interactive sales analysis dashboard built using Python, Streamlit, Pandas, and Plotly.

## Features
- Interactive sales visualizations
- Sales and product performance analysis
- Key performance indicators (KPIs)
- Data-driven business insights

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- Excel

## Dataset
The project uses an Excel dataset containing Blinkit-style sales data.

## How to Run
1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the dashboard:

   streamlit run kit.py
